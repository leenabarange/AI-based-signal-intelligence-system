# AI-Based Signal Intelligence System

## Overview
A Python-based signal processing and machine learning project that explores noisy signal analysis, noise filtering, frequency-domain analysis, and signal classification.

## Objectives
- Generate and analyze synthetic signals
- Add noise and apply low-pass filtering
- Analyze frequency components using FFT
- Train a machine learning model to classify sine, square, and triangle signals
- Visualize signals through an interactive dashboard

## Technologies Used
- Python
- NumPy
- Matplotlib
- SciPy
- scikit-learn
- Google Colab
- ipywidgets

## Current Results
- Generated clean and noisy synthetic signals
- Applied low-pass filtering
- Identified the dominant frequency using FFT
- Achieved 98.33% accuracy on the simulated held-out test dataset
- Tested an interactive signal visualization dashboard

> Note: The reported accuracy is based on simulated data and does not represent validated real-world performance. The dashboard and classifier are currently separate components.

## How to Run
1. Open the notebook `AI_base_signal_intelligence_system.ipynb` in Google Colab.
2. Run the cells from top to bottom.
3. Install any missing libraries if prompted.
4. Use the interactive dashboard after running its setup cell.
